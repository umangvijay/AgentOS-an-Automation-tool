# AgentOS — Start Here

AgentOS is an **autonomous AI workspace**. You type what you want in plain language; it plans the work, builds any app connectors (MCP tools) it is missing, executes them against live APIs and websites, recovers from failures, and hands you real results — downloadable files, emails, live API data.

**60-second tour**
1. Sign in (or use Continue as Guest).
2. Type a goal in the chat: *"Check the health of example.com"*, *"Create MCP tools from https://…/openapi.json"*, or *"Research the top MCP servers on GitHub and save a report I can download"*.
3. Watch the Execution Timeline — every tool call streams in live.
4. Open **Runs** for full DAG detail, **Integrations** for your MCP tools, **Vault** for secrets.
