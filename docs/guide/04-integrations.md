# Integrations Page

Lists every MCP you've built: status, tool count, trust tier, circuit-breaker health.

- **Build New Integration** — the four Forge paths (URL / paste spec / website / description).
- **Integration detail** — all tools with descriptions, **Run Test** (live probe), **Disable/Enable**, attach API key (encrypted into Vault), Delete.
- **Circuit breaker**: repeated failures open the breaker to protect the upstream; it resets automatically.
